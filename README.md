# Floral Fantasy 

Floral Fantasy is a premium web-based flower boutique platform designed to showcase and facilitate the ordering of fresh blooms and artistic floral arrangements. The project focuses on providing a seamless and aesthetically pleasing user experience using modern web technologies.

## Key Features
*   **Responsive Design:** Fully optimized for all devices, including smartphones, tablets, and desktops.
*   **User-Friendly Interface:** A clean, modern, and intuitive UI that enhances the browsing experience.
*   **Member Login:** A dedicated login portal for customers to manage their accounts and track orders.
*   **Curated Collections:** Organized floral categories to help users find the perfect arrangement for any occasion.

## Technologies Used
*   **HTML5** - For structuring the web content.
*   **CSS3** - For advanced styling, layouts, and smooth animations.
*   **JavaScript** - To add interactivity and dynamic behavior to the site.
*   **Google Fonts** - Utilizing modern typography like 'Poppins'.
*   **Font Awesome** - For professional-grade icons.

## Installation and Usage
1.  Clone this repository:
    ```bash
    git clone [https://github.com/hiru263/Floral-Fantasy.git](https://github.com/hiru263/Floral-Fantasy.git)
    ```
2.  Navigate to the project folder.
3.  Open the `index.html` file in your preferred web browser (e.g., Google Chrome).
